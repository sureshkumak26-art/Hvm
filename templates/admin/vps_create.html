How Routed IPs Work

The panel uses LXC's routed NIC type. A device named pubip is attached to the container with the public IP, which appears inside the guest as eth1. Outbound traffic uses the host's parent interface; inbound traffic is routed by the upstream gateway to this host.

  • The IP must already be routed (or assignable) to this host.
  • Default mask is /32 — that's standard for routed NICs.
  • The container will be restarted at the end of the network step.
  • Subnet + parent interface are saved in metadata so reinstalls reuse them.
Notes
Public IP is optional at create time. You can also add or change it later from the VPS's Manage IP page, which uses the exact same backend.
